    Clique em "Gravar" e pressione a combinação (precisa de ao menos um modificador + uma tecla — o sistema não permite usar Super, Ctrl, Alt ou Shift sozinhos diretamente). Se a tecla Super não responder, seu sistema provavelmente já usa essa combinação para outra coisa (ex.: o GNOME reserva Super+Espaço para trocar o idioma do teclado por padrão).

    ou
    Só a tecla Super (toque único)
    Usa o utilitário "xcape" para detectar Super pressionado e solto sozinho. Requer instalar um pacote do sistema.

    Arquivos .AppImage dentro dessas pastas aparecem na busca, junto com os demais apps.
